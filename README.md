### Türkiye'deki il ve ilçelerin merkez noktalarının enlem ve boylam değerleri

Veriler [Harita Genel Müdürlüğü](https://www.harita.gov.tr/index) websitesinden alınmıştır.

[db](turkey_city_district_coordinates.db) dosyası SQLite veritabanı dökümanıdır. [CSV](turkey_city_district_coordinates.csv) dosyasındaki değerlerin virgülden sonra iki basamağa yuvarlanmış halini içerir. Veriler `districts` tablosunda yer alır. Sütunlar: `city`, `district`, `latitude`, `longitude`.
